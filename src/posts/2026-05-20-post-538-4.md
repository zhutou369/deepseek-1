## 系統架構設計：實現高吞吐量

要構建一個高吞吐量嘅跨境客服系統，單純調用 DeepSeek API 係唔夠嘅，我哋需要一套精巧嘅系統架構嚟支持。

### 前端介面與集成

系統嘅第一層係客戶與客服系統互動嘅介面。

*   **網頁 Widget 與即時通訊 App 集成：** 提供多渠道接入，包括直接嵌入網站嘅聊天 Widget、以及集成到 WhatsApp、Facebook Messenger、WeChat 等主流即時通訊應用，方便客戶隨時隨地發起查詢。
*   **API Gateway (API 閘道)：** 作為所有前端請求嘅統一入口，負責認證、授權、流量控制、請求轉發等功能，保護後端服務。

### 中間件與智能路由

中間件係實現高吞吐量同穩定性嘅核心組件。

*   **訊息隊列 (Message Queues)：** 引入 Kafka、RabbitMQ 等訊息隊列，將前端請求異步化，緩衝流量高峰，確保 DeepSeek API 唔會被瞬間嘅大量請求壓垮。客戶查詢會先進入隊列，再由後端工作者（Worker）按序或並發處理。
*   **請求限速與負載平衡：** 喺 API Gateway 層同 DeepSeek API 調用層，設置限速策略，防止惡意攻擊同過度調用。同時，利用負載平衡器（Load Balancer）將請求分發到多個處理單元，提高系統整體處理能力。

有效管理 DeepSeek API 嘅調用，係確保系統高吞吐量同穩定性嘅關鍵。
