## 短影音內容規劃：從概念到清晰的指令

### 1. 確定短影音主題與目標受眾

在與 DeepSeek 互動之前，請先明確您的短影音主題、欲傳達的核心訊息、目標觀眾是誰，以及您希望達到的效果（例如：增加品牌知名度、促銷產品、提供資訊等）。這些要素將是您構建提示詞的關鍵基礎。

## 將文案轉化為分鏡腳本

文案是文字，而短影音更需要視覺化。分鏡腳本則負責將文字內容轉換為具體的視覺、聽覺元素和時間規劃。

### 3. 從文案生成分鏡腳本的提示詞

在獲得滿意的文案後，您可以利用 DeepSeek 的連續性對話能力，基於剛才的文案，進一步生成分鏡腳本。

**推薦的提示詞結構：**

```
請根據我剛才提供的短影音文案，為其生成一份詳細的分鏡腳本。
腳本需包含以下欄位：
1. 場景編號 (Scene No.)
2. 時間碼 (Timecode) 或預計時長 (Duration)
3. 畫面描述 (Visual Description)：包含鏡頭運動、畫面構成、視覺元素等。
4. 旁白/對白 (Narration/Dialogue)：直接引用文案內容。
5. 背景音樂/音效 (BGM/Sound Effects)：建議具體音樂風格或音效。
6. 文字疊加 (On-screen Text)：建議出現的關鍵字或標題。

請以繁體中文輸出，並以清晰的表格格式呈現。
```

## 進階應用：結合 DeepSeek API 實現自動化工作流

對於需要大量內容生成或整合至現有系統的用戶，DeepSeek 提供了 API 接口，實現更高級的自動化。

### 4. 獲取 DeepSeek API 密鑰

首先，您需要註冊 DeepSeek 開發者賬戶，並在平台（例如 DeepSeek 開發者平台）獲取 API 密鑰。這將是您程式化訪問 DeepSeek 服務的憑證。請務必妥善保管您的 API 密鑰。

### 5. 編寫 Python 自動化腳本

以下是一個簡化的 Python 腳本範例，展示如何使用 DeepSeek API 自動生成短影音文案與分鏡腳本。

```python
import os
from deepseek import DeepSeek

# 假設您已將 API 金鑰設定為環境變數 DEEPSEEK_API_KEY
# 或者您可以直接在這裡設定：api_key = "YOUR_DEEPSEEK_API_KEY"
deepseek_api_key = os.environ.get("DEEPSEEK_API_KEY")

if not deepseek_api_key:
    raise ValueError("請設定環境變數 DEEPSEEK_API_KEY")

client = DeepSeek(api_key=deepseek_api_key)

def generate_short_video_content(topic, duration="30-45 秒", platform="TikTok/Reels"):
    """
    使用 DeepSeek API 生成短影音文案和分鏡腳本。
    """
    
    # --- 生成文案 ---
    script_prompt = f"""
你是一位擅長創作短影音內容的資深編輯。
請為以下主題生成一份約 {duration} 的短影音文案，適用於 {platform}。
文案需包含：
1. 引人入勝的開場白 (Hook)
2. 核心內容（具體細節、展示）
3. 互動式結尾或行動呼籲 (Call to Action, CTA)
4. 情感基調：活潑、充滿食慾、帶有文化探索感。
5. 融入「菠蘿油」、「香港美食」、「地道小食」等關鍵字。

主題：{topic}
目標受眾：年輕遊客、美食愛好者、對香港文化感興趣的人。
核心訊息：菠蘿油不僅美味，更蘊含香港獨特的飲食文化。

請以繁體中文輸出，並以以下格式呈現：
[開場白]
[內容一]
[內容二]
[結尾/CTA]
[推薦 Hashtag]
"""
    print("正在生成短影音文案...")
    script_response = client.chat.completions.create(
        model="deepseek-chat", # 選擇合適的 DeepSeek 模型
        messages=[{"role": "user", "content": script_prompt}],
        temperature=0.7,
        max_tokens=800
    )
    video_script = script_response.choices[0].message.content
    print("\n--- 生成的短影音文案 ---")
    print(video_script)

    # --- 生成分鏡腳本 ---
    storyboard_prompt = f"""
請根據以下短影音文案，為其生成一份詳細的分鏡腳本。
腳本需包含以下欄位：
1. 場景編號 (Scene No.)
2. 預計時長 (Duration) (秒)
3. 畫面描述 (Visual Description)：包含鏡頭運動、畫面構成、視覺元素等。
4. 旁白/對白 (Narration/Dialogue)：直接引用文案內容。
5. 背景音樂/音效 (BGM/Sound Effects)：建議具體音樂風格或音效。
6. 文字疊加 (On-screen Text)：建議出現的關鍵字或標題。

請以繁體中文輸出，並以清晰的 Markdown 表格格式呈現。

短影音文案：
{video_script}
"""
    print("\n正在生成分鏡腳本...")
    storyboard_response = client.chat.completions.create(
        model="deepseek-chat", # 選擇合適的 DeepSeek 模型
        messages=[{"role": "user", "content": storyboard_prompt}],
        temperature=0.5,
        max_tokens=1200
    )
    storyboard = storyboard_response.choices[0].message.content
    print("\n--- 生成的分鏡腳本 ---")
    print(storyboard)
    
    return video_script, storyboard

# 執行範例
if __name__ == "__main__":
    video_topic = "香港地道美食「菠蘿油」的製作與品嚐體驗。"
    script, board = generate_short_video_content(video_topic)
```

## 優化與迭代：提升內容品質

DeepSeek 生成的內容是基於您提供的提示詞。如果初次生成的文案或腳本不盡理想，您可以：

1.  **調整提示詞：** 更加具體化您的要求，例如增加更多情感描述、指定更詳細的畫面元素。
2.  **提供反饋：** 在 DeepSeek Chat 中，您可以直接指出哪些部分需要改進，讓模型在後續對話中進行修正。
3.  **調整參數：** 在 API 調用中，`temperature` 參數控制生成內容的「隨機性」。較高的 `temperature` (如 0.8-1.0) 可能產生更有創意但較不可控的結果；較低的 `temperature` (如 0.2-0.5) 則會生成更保守、更貼合主題的內容。
4.  **多次生成：** 嘗試以相同的提示詞生成多次，從中選擇最滿意的結果。
