### 步驟 1：登入 DeepSeek 平台

首先，前往 `chat.deepseek.com`。如果您尚未註冊，請根據提示完成註冊與登入。登入後，您將看到一個簡潔的聊天介面，可以在此輸入您的查詢。

### 步驟 2：建立清晰的查詢指令（Prompt Engineering for Tax Professionals）

有效的查詢指令（Prompt）是獲取精準回覆的關鍵。對於稅務專業人士而言，指令應盡可能明確，包含以下要素：

*   **司法管轄區：** 明確指出涉及的國家或地區（例如：香港、中國內地、新加坡、美國）。
*   **稅務類型：** 具體說明是利得稅、增值稅、消費稅、個人所得稅、預扣稅等。
*   **具體問題/情境：** 詳細描述您需要解決的問題或分析的情境。
*   **時間範圍（如適用）：** 指定您關注的法規生效日期或適用期間。
*   **輸出格式要求：** 例如，要求條列式清單、表格比較、摘要或詳細解釋。
*   **參考法規依據：** 要求 DeepSeek 提供相關法規條文、政府指南或案例連結（儘管這些連結可能需要人工驗證）。

**範例查詢指令：**

「請比較香港與中國內地關於企業所得稅中研發（R&D）費用加計扣除的最新政策差異。具體列出：
1.  兩地的稅收優惠比例；
2.  適用研發活動的範圍；
3.  申請條件與所需文件。
請以條列式呈現，並在可能情況下，註明相關法規名稱。」

### 步驟 3：分析與驗證 DeepSeek 的回覆

DeepSeek 將根據您的指令生成回覆。在收到回覆後，請務必進行以下操作：

*   **關鍵資訊核實：** 針對 DeepSeek 提供的關鍵稅率、百分比、法規名稱或條文，務必透過官方稅務網站、專業稅務數據庫或其他權威來源進行交叉核對。DeepSeek 訓練數據有其局限性，可能無法涵蓋最即時的法規更新。

### DeepSeek API 基礎使用概念：

1.  **獲取 API Key：** 您需要前往 DeepSeek 開發者平台獲取 API 密鑰（API Key），這是調用 API 的身份憑證。

3.  **發送 API 請求：** 透過 HTTP POST 請求將您的查詢指令發送到 DeepSeek API 端點。請求通常包含 API Key、模型名稱以及您的 Prompt。
4.  **接收與處理回覆：** API 會返回一個 JSON 格式的響應，其中包含 DeepSeek 生成的文本。您需要解析這個 JSON 響應，提取所需資訊。

### 概念性 API 調用示例（Python 偽代碼）：

以下是一個簡單的 Python 偽代碼，展示如何利用 DeepSeek API 進行跨境稅務查詢：

```python
import requests
import json

# 配置您的 DeepSeek API 金鑰和端點
DEEPSEEK_API_KEY = "YOUR_DEEPSEEK_API_KEY" # 請替換為您的實際金鑰
DEEPSEEK_API_ENDPOINT = "https://api.deepseek.com/chat/completions" # 示例端點，請查閱官方文檔確認

def query_deepseek_tax(prompt_text):
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
    }
    payload = {
        "model": "deepseek-chat", # 選擇合適的模型，例如 deepseek-chat 或 deepseek-coder
        "messages": [
            {"role": "user", "content": prompt_text}
        ],
        "temperature": 0.7, # 控制回覆的隨機性，0.7為常用值
        "max_tokens": 1024 # 限制回覆的最大字數
    }

    try:
        response = requests.post(DEEPSEEK_API_ENDPOINT, headers=headers, data=json.dumps(payload))
        response.raise_for_status() # 檢查請求是否成功
        result = response.json()
        
        # 解析 DeepSeek 的回覆
        if result and result.get("choices"):
            return result["choices"][0]["message"]["content"]
        else:
            return "未能從 DeepSeek 獲取有效回覆。"
    except requests.exceptions.RequestException as e:
        print(f"API 請求錯誤: {e}")
        return None

# 示例查詢
tax_query = """
請提供香港利得稅對於海外收入的徵稅原則，並簡要說明離岸豁免（offshore exemption）的適用條件和最新判例趨勢。
請列出主要法規依據。
"""

deepseek_response = query_deepseek_tax(tax_query)
if deepseek_response:
    print("DeepSeek 回覆：")
    print(deepseek_response)

# 更複雜的查詢示例
comparison_query = """
請比較新加坡與馬來西亞在股息預扣稅（dividend withholding tax）方面的異同，特別是在涉及雙邊稅收協定（DTA）下的稅率優惠。
請以表格形式呈現比較結果，並註明參考條文。
"""
comparison_response = query_deepseek_tax(comparison_query)
if comparison_response:
    print("\n----- 新加坡與馬來西亞股息預扣稅比較 -----")
    print(comparison_response)
```

這個偽代碼展示了如何構造一個 API 請求，將稅務問題發送給 DeepSeek，並獲取其回覆。實際應用中，您可以將 `query_deepseek_tax` 函數整合到更大型的系統中，例如自動化報告生成工具或內部知識庫。

3.  **強調人類專業判斷：** AI 無法替代資深會計師或稅務顧問的專業判斷、經驗和對客戶具體情況的深入理解。最終的稅務建議和決策必須由專業人士做出。

5.  **成本管理：** 使用 DeepSeek API 會產生費用，事務所應監控其 API 使用量，並根據實際需求選擇合適的模型和請求頻率，以控制成本。
