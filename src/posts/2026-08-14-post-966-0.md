## 情感共鳴：不只敘述，更要感受

情感共鳴的文本，不只是描述一種情緒，而是要讓讀者感同身受，彷彿親身經歷。這需要 AI 在語言選擇、情境描繪、敘事節奏等方面都進行精細的調整。在 DeepSeek 上實踐提示詞工程，核心目標是將抽象的情感指令，轉化為具體且可執行的語言模型輸入。

要讓 AI 輸出具備情感共鳴的長文，我們需要從以下幾個維度著手：

### 1. 精準的角色與情境設定

AI 無法憑空產生情感，它需要一個明確的「舞台」和「演員」。為 DeepSeek 設定一個具體的角色（Persona）和清晰的情境（Context），是營造情感氛圍的第一步。

**操作指南：**

*   **指定角色：** 讓 DeepSeek 扮演一個具有特定背景、個性、情感傾向的角色。例如：「你是一位經歷過人生跌宕的智者」、「你是一位觀察入微、富有同情心的記者」、「你是一位初次踏足大都會，充滿好奇與憧憬的年輕人」。
*   **構建情境：** 詳細描述故事發生的時間、地點、起因、主要事件及目標讀者。情境越具體，AI 越能捕捉其情感基調。
*   **範例提示詞結構：**
    ```
    你現在是一位【角色描述，例如：一位在香港生活了三十年、對城市變遷有深刻體會的文化觀察家】。
    你的任務是為【目標讀者，例如：希望了解香港歷史與人情味的外國遊客】撰寫一篇【文本類型，例如：關於某個舊社區逐漸消失的長篇散文】。
    文章需要傳達出【主要情感，例如：懷舊、失落、對逝去美好的留戀，但同時也有一絲對未來的不確定與希望】。
    情境設定：【詳細描述場景，例如：舊區清晨的街市、斑駁的唐樓、巷弄裏傳來的聲響、老店舖的故事】。
    ```

### 2. 明確的情感指示與情緒曲線

僅僅指定「悲傷」或「喜悅」是不夠的。情感是複雜的，往往有多個層次和變化。在長文中，情感更需要一個發展和轉變的過程，形成「情緒曲線」。

**操作指南：**

*   **具體化情感詞彙：** 避免籠統的詞語，使用更具體的表達，例如將「悲傷」細化為「淡淡的憂愁」、「深沉的哀慟」、「無奈的感傷」等。
*   **設定情緒階段：** 規劃文章在不同階段的情感變化。例如：
    *   **開端：** 鋪陳平靜或略帶困惑的情緒。
    *   **發展：** 逐漸累積緊張、興奮、失落或希望。
    *   **高潮：** 情緒達到頂點，可能是衝突、領悟、釋放。
    *   **結尾：** 情感沉澱，留下深思、寬慰、或未完待續的懸念。
*   **利用隱喻與象徵：** 指示 DeepSeek 使用隱喻、象徵手法來烘托情感。例如：「如霧般瀰漫的思念」、「雨點敲打窗戶，彷彿在低聲訴說著什麼」。
*   **範例提示詞片段：**
    ```
    文章開篇請用一種略帶疏離感的筆觸，描繪主角對陌生城市的初次印象，帶有一絲迷茫與好奇。
    隨著故事發展，當主角遇到困難時，情感應轉為焦慮與掙扎，但同時也展現出不屈的韌性。
    在故事的高潮，主角經歷頓悟，情緒從低谷躍升至豁然開朗的喜悅，並帶有一絲淚水。
    結尾處，情感應趨於平靜，但留有深遠的希望與對未來的期盼。
    ```

### 3. 豐富的感官描寫與細節呈現

情感往往透過感官體驗來傳達。視覺、聽覺、嗅覺、味覺、觸覺的細節描寫，能讓讀者更身臨其境，從而產生共鳴。

**操作指南：**

*   **多感官指令：** 明確要求 DeepSeek 在描寫中融入多種感官元素。例如：「不僅要描述畫面，還要加入聲音、氣味，甚至是輕微的觸感。」
*   **具體細節：** 提供或要求 AI 創造具體、生動的細節。例如：「風吹過窗簾的沙沙聲」、「空氣中瀰漫著舊書與茶葉混合的氣味」、「指尖輕觸粗糙的石牆」。
*   **連結內心情感：** 提示 AI 將外部感官描寫與主角的內心感受聯繫起來。
*   **範例提示詞片段：**
    ```
    請詳細描寫主角在雨中漫步時的感官體驗：雨水打濕髮梢的冰冷觸感、街燈在水窪中的模糊倒影、遠處傳來車輛駛過濺起水花的聲音、以及空氣中那股泥土與潮濕的獨特氣味。讓這些感官細節烘托出主角此刻內心的孤寂與沉思。
    ```

### 4. 敘事語氣與風格的引導

語氣（Tone）和風格（Style）是塑造文章情感的關鍵。是莊重、幽默、沉鬱、溫馨，還是充滿力量？

**操作指南：**

*   **明確語氣詞：** 直接指定文章的整體語氣，例如：「請以溫暖而充滿力量的語氣撰寫」、「請用一種帶有黑色幽默的諷刺語氣」。
*   **參考範本：** 如果有特定作者或作品的風格作為參考，可以提示 DeepSeek 學習其風格。例如：「請嘗試模仿余華在《活著》中的那種平實而深沉的敘事風格」。
*   **修辭手法：** 指示 DeepSeek 運用特定的修辭手法，如排比、比喻、擬人、反問等，以增強文章的感染力。
*   **範例提示詞片段：**
    ```
    請以一種略帶懷舊、但又不失積極向上的語氣，講述一個關於堅持夢想的故事。
    在敘述過程中，可以適度運用比喻和擬人手法，讓文字更具詩意。
    避免過於激昂的詞語，保持一種沉穩而內斂的敘事節奏。
    ```

### 5. 結構化輸出與迭代優化

長文需要清晰的結構來承載情感。同時，首次生成的內容可能不完美，需要透過迭代優化來不斷提升。

**操作指南：**

*   **提供大綱或段落指引：** 為 DeepSeek 提供文章的章節大綱或每個段落的重點提示，引導其按邏輯鋪陳情感。
*   **指定字數或篇幅：** 針對每個部分或整個文章指定大致的字數要求，有助於 AI 分配內容。
*   **分段生成與銜接：** 對於非常長的文本，可以考慮將其分解為幾個部分，分批生成後再進行銜接和調整。
*   **迭代修訂：** 第一次生成後，仔細審閱，針對情感表達不足或過度之處，提供具體修改建議，例如：「第二段的情緒不夠強烈，請增加更多細節描寫來強化主角的掙扎感。」
*   **多輪對話：** 在 chat.deepseek.com 平台上，利用多輪對話的優勢，逐步引導 AI 深入情感。例如，先讓它生成故事骨架，再針對特定情節要求它「用更感人的方式描寫」或「增加一個能觸發讀者共鳴的轉折點」。
*   **範例迭代指令：**
    ```
    第一輪：請為我撰寫一篇關於「城市邊緣人的奮鬥」的長文草稿，字數約 800 字。
    第二輪：請重新審視草稿中的第三段，將主角的內心掙扎描寫得更具畫面感與情緒張力，使用更多感官細節。
    第三輪：在文章結尾，請加入一段對未來充滿希望的展望，但語氣不要過於樂觀，帶點現實的沉重感。
    ```

## 實用範例：一篇關於香港情懷的長文

以下是一個結合上述技巧的 DeepSeek 提示詞範例，旨在生成一篇關於香港舊區變遷、帶有懷舊與感傷情懷的長文。

```
你現在是一位深愛香港、見證了城市數十年變遷的資深專欄作家，筆觸細膩、富有觀察力。
你的任務是為【本地及海外讀者】撰寫一篇【1200字左右】的長篇散文，主題是【香港一個逐漸消失的舊區（例如深水埗、土瓜灣）的變遷與人情味】。
文章應傳達出【對逝去時光的深沉懷舊、對小人物命運的溫柔關懷、對城市發展的複雜情感，以及一絲對未來不確定的迷惘與期盼】。

文章結構如下：
1. **引言 (約150字):** 以具體場景開篇，描繪舊區清晨的熱鬧與獨特氣味，建立懷舊氛圍。
2. **往昔歲月 (約400字):** 回溯舊區鼎盛時期的景象，著重描寫舊式店鋪（如理髮店、雜貨店、大牌檔）的具體細節、老闆與街坊的互動，展現濃郁的人情味與生活氣息。使用多感官描寫：聲音（小販叫賣、麻雀聲）、氣味（街市魚腥、茶餐廳奶茶香）、觸感（老舊木頭桌椅）。
3. **變遷的痕跡 (約400字):** 描寫近年來舊區面臨的挑戰與變化，例如：舊建築的拆卸、新式商舖的進駐、老居民的遷離。語氣轉為淡淡的憂傷與無奈，但避免過於煽情。透過具體的例子（例如一間老店舖的結業、一個熟悉街坊的離去）來呈現這種變遷。
4. **留戀與展望 (約250字):** 表達對舊區獨特文化與人情味的留戀，同時思考在發展洪流中，我們如何保存這些珍貴記憶。結尾可帶有一絲對香港未來發展的深思與期盼，不必提供明確答案，留給讀者思考空間。

整體語氣應是：【溫和、沉靜、富有哲思，帶有淡淡的感傷但又不失對生命力的肯定】。
請運用【比喻、擬人、排比】等修辭手法，讓文字更具感染力。
避免使用過於學術或口號式的語言，力求貼近人心的敘述。
```
