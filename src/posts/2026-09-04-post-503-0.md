## 了解 11ty 的文章結構與 DeepSeek 提示詞基礎

11ty 博客文章通常由兩個主要部分組成：

1.  **元數據 (Front Matter)**：位於文件頂部的 YAML 或 JSON 格式數據塊，被三條橫線 `---` 包裹。它定義了文章的標題、描述、日期、標籤、佈局等屬性。
2.  **文章主體 (Body Content)**：元數據之後的 Markdown 格式內容，包含實際的文章文字、圖片、代碼塊等。

DeepSeek 模型（可透過 chat.deepseek.com 體驗或使用 DeepSeek API）能夠理解並生成結構化文本。我們的目標是設計提示詞，讓 DeepSeek 輸出這兩種格式的內容。

### 設計高效提示詞的原則

*   **明確指令**：清晰地告知模型您需要什麼，例如「生成一篇關於 [主題] 的博客文章」。
*   **指定輸出格式**：明確要求輸出 YAML Front Matter 和 Markdown 格式的內容。
*   **提供範例**：給出一個預期的 Front Matter 和 Markdown 結構範例，模型更容易模仿。
*   **定義關鍵元素**：列出 Front Matter 中必須包含的字段及其預期格式。
*   **限制字數與風格**：例如，要求文章內容達到指定字數範圍，並指定寫作風格（例如「實用教程風格」、「輕鬆幽默」）。

## DeepSeek API 與自動化流程構建

要實現全自動生成，你需要使用 DeepSeek API 將提示詞發送給模型並獲取響應。這裡以 Python 為例，演示如何整合 DeepSeek API。

### 獲取 DeepSeek API 金鑰

首先，你需要註冊 DeepSeek 平台並獲取 API 金鑰。訪問 [chat.deepseek.com](https://chat.deepseek.com) 進入個人設定或開發者頁面即可找到。

### Python 自動化腳本示例

以下是一個簡化的 Python 腳本，展示如何：
1.  呼叫 DeepSeek API 生成 Front Matter。
2.  呼叫 DeepSeek API 生成文章主體。
3.  將兩者合併並保存為一個 `.md` 文件。

```python
import os
import requests
import datetime
import re

# 請替換為您的 DeepSeek API 金鑰
DEEPSEEK_API_KEY = os.environ.get("DEEPSEEK_API_KEY") # 建議從環境變量獲取
DEEPSEEK_API_URL = "https://api.deepseek.com/chat/completions"

def call_deepseek_api(prompt, model="deepseek-chat"):
    """呼叫 DeepSeek API 獲取生成內容"""
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
    }
    data = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "stream": False # 非串流模式
    }
    try:
        response = requests.post(DEEPSEEK_API_URL, headers=headers, json=data)
        response.raise_for_status() # 檢查 HTTP 錯誤
        return response.json()['choices'][0]['message']['content']
    except requests.exceptions.RequestException as e:
        print(f"API 請求錯誤: {e}")
        if response:
            print(f"錯誤響應: {response.text}")
        return None

def generate_11ty_post(topic):
    """根據主題生成完整的 11ty 博客文章"""
    today = datetime.date.today().strftime("%Y-%m-%d")

    # 1. 生成 Front Matter
    fm_prompt = f"""你是一個專業的博客文章生成助手。請為一篇關於「{topic}」的技術教程生成 YAML 格式的 Front Matter。

Front Matter 必須包含以下字段：
- `title`: (文章標題，繁體中文，40字內，與主題相關)
- `description`: (文章簡要描述，概括內容與解決的問題，繁體中文，60-80字)
- `date`: (文章發佈日期，格式為 YYYY-MM-DD，請使用 {today})
- `generated`: true (固定值)
- `tags`: ["posts", "deepseek", "11ty", "自動化"] (至少包含這些標籤，可增加相關標籤)
- `layout`: "layouts/post.njk" (固定值)
- `permalink`: (文章的 URL 路徑，格式為 "/posts/YYYY-MM-DD-你的英文slug-503/index.html"，請用英文小寫連字符slug替換「你的英文slug」，基於文章標題生成)

請直接輸出 YAML 格式的 Front Matter 內容，不要包含任何額外說明。
"""
    front_matter_content = call_deepseek_api(fm_prompt)
    if not front_matter_content:
        return None, "無法生成 Front Matter"

    # 提取 title 以生成 permalink slug
    title_match = re.search(r'title:\s*"(.*?)"', front_matter_content)
    if title_match:
        generated_title = title_match.group(1)
        # 簡單的 slug 化處理
        slug = re.sub(r'[^\w\s-]', '', generated_title).strip().lower()
        slug = re.sub(r'[-\s]+', '-', slug)
        # 用動態生成的 slug 和日期替換 permalink 佔位符
        final_permalink = f"/posts/{today}-{slug}-503/index.html"
        front_matter_content = re.sub(r'permalink:\s*".*?"', f'permalink: "{final_permalink}"', front_matter_content)
    else:
        # 如果無法從生成的 Front Matter 中提取 title，則嘗試基於原始 topic 生成 slug
        slug = re.sub(r'[^\w\s-]', '', topic).strip().lower()
        slug = re.sub(r'[-\s]+', '-', slug)
        final_permalink = f"/posts/{today}-{slug}-503/index.html"
        front_matter_content = re.sub(r'permalink:\s*".*?"', f'permalink: "{final_permalink}"', front_matter_content)

    # 2. 生成文章主體
    body_prompt = f"""請為主題為「{topic}」的技術教程生成一篇詳細的 Markdown 格式文章。

文章要求：
- 使用繁體中文。
- 長度約 800-1200 字。
- 內容結構清晰，包含引言、至少三個二級標題 (##)、多個三級標題 (###)。
- 多使用步驟清單、代碼塊 (請使用 Python 程式碼範例，並確保有語言標識如 ```python)、表格來提升可讀性。
- 語氣專業、實用，面向具備基礎編程知識的讀者。
- 避免使用虛構的「官方」「權威入口」等表述，DeepSeek 相關請寫 chat.deepseek.com 或 DeepSeek API。
- 文章結尾應有簡潔的總結。

請直接輸出 Markdown 格式的文章內容，不要包含任何額外說明或 Front Matter。
"""
    body_content = call_deepseek_api(body_prompt)
    if not body_content:
        return None, "無法生成文章主體"

    # 3. 合併並保存
    full_content = f"{front_matter_content}\n\n{body_content}"
    
    # 創建一個基於 slug 的文件名
    filename = f"posts/{today}-{slug}.md" # 假設 posts 是你的 11ty 內容目錄
    
    with open(filename, "w", encoding="utf-8") as f:
        f.write(full_content)
    
    return filename, "文章生成成功"

if __name__ == "__main__":
    if not DEEPSEEK_API_KEY:
        print("請設定環境變量 DEEPSEEK_API_KEY")
    else:
        target_topic = "使用 DeepSeek API 自動化部署 Laravel 應用程式的最佳實踐"
        generated_file, status_msg = generate_11ty_post(target_topic)
        if generated_file:
            print(f"{status_msg}: {generated_file}")
        else:
            print(f"生成失敗: {status_msg}")

```
