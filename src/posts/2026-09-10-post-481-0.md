### II. 設計提示詞（Prompt Engineering）的核心思路

提示詞（Prompt）是與 DeepSeek 溝通的關鍵。一個精心設計的提示詞能引導模型生成更精準、更有用的行程。

#### 1. 角色設定

賦予 DeepSeek 一個明確的角色，使其回答更具專業性和針對性。例如，將其設定為「香港本地資深旅遊規劃師」。

#### 2. 輸入要求

清晰地定義用戶需要提供的資訊，例如：

*   **主要興趣：** (例如：美食、購物、文化遺產、自然風光、夜生活、親子活動)
*   **旅遊預算：** (例如：經濟型、中等、奢華型)
*   **可用時間：** (例如：上午9點至下午6點)
*   **同行人數：** (例如：2位成人，1位兒童)
*   **特殊偏好：** (例如：避免人多、想去離島、不喜歡海鮮)
*   **出發地點：** (例如：中環、尖沙咀)

#### 3. 輸出格式要求

明確要求 DeepSeek 以結構化的方式輸出行程，例如 JSON 格式，方便程式解析。可以要求包含：

*   每日行程總覽
*   每個景點的名稱、地址、建議停留時間、交通方式、簡要介紹
*   餐飲建議（午餐、晚餐）
*   總預估花費
*   行程總結與溫馨提示

#### 4. 範例提示詞

以下是一個用於生成香港一日遊行程的複合型提示詞範例：

```python
prompt_template = """
你是一位資深的香港本地旅遊規劃師。你的任務是根據用戶提供的需求，為他們設計一個詳盡、有趣且可行的香港一日遊行程。

請嚴格遵循以下步驟和要求：

1.  **理解用戶需求：** 仔細閱讀用戶的興趣、預算、可用時間、同行人數及特殊偏好。
2.  **生成行程：**
    *   行程應從用戶指定的「出發地點」開始，並考慮香港的交通便利性，優化路線，減少往返時間。
    *   行程需包含至少 3-5 個景點/活動，並包括午餐和晚餐建議。
    *   景點和活動要與用戶的興趣和預算相符。
    *   請提供每個景點的簡要介紹、建議停留時間及建議交通方式（例如：港鐵、巴士、的士）。
    *   餐飲建議需明確地點和菜系。
    *   請在行程中加入適當的休息時間或彈性時間。
    *   考慮同行人數，特別是有兒童的情況，可加入適合親子的活動。
3.  **輸出格式：**
    *   請以 **JSON 格式** 輸出結果，確保所有鍵名為英文小寫，值為繁體中文。
    *   JSON 應包含以下頂層鍵：`summary` (行程總結), `itinerary_details` (詳細行程列表), `estimated_cost` (預估花費), `tips` (溫馨提示)。
    *   `itinerary_details` 應為一個列表，每個元素代表一個時間段或活動，包含：`time_slot`, `activity_name`, `description`, `location`, `suggested_duration`, `transportation`, `note`。
    *   `estimated_cost` 應包含 `currency` 和 `amount`。
    *   `tips` 應為一個列表，包含多條建議。

**用戶需求範例：**
興趣：美食、購物、文化體驗
預算：中等
可用時間：上午10點至晚上8點
同行人數：2位成人
特殊偏好：希望體驗地道文化，不喜歡太商業化的景點。
出發地點：銅鑼灣

**請根據以下用戶輸入，生成行程：**
興趣：{user_interest}
預算：{user_budget}
可用時間：{user_time}
同行人數：{user_pax}
特殊偏好：{user_preferences}
出發地點：{user_departure}
"""
```

### III. DeepSeek API 調用實作

一旦提示詞設計完成，就可以透過 Python 程式碼調用 DeepSeek API。

#### 1. API 端點與請求方法

DeepSeek API 的聊天補全端點通常與 OpenAI 兼容，為 `https://api.deepseek.com/chat/completions`。請求方法為 `POST`。

#### 2. Python 代碼示例

以下是一個使用 `requests` 函式庫發送 API 請求的示例：

```python
import requests
import json
import os

# 從環境變數獲取 API 金鑰，提高安全性
DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY", "YOUR_DEEPSEEK_API_KEY") 
# 如果你只是測試，可以直接寫入金鑰，但在生產環境中強烈建議使用環境變數

API_ENDPOINT = "https://api.deepseek.com/chat/completions"

def get_personalized_itinerary(
    user_interest: str,
    user_budget: str,
    user_time: str,
    user_pax: str,
    user_preferences: str,
    user_departure: str
):
    """
    根據用戶輸入，調用 DeepSeek API 生成個性化香港一日遊行程。
    """
    
    # 填充提示詞模板
    filled_prompt = prompt_template.format(
        user_interest=user_interest,
        user_budget=user_budget,
        user_time=user_time,
        user_pax=user_pax,
        user_preferences=user_preferences,
        user_departure=user_departure
    )

    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
    }

    payload = {
        "model": "deepseek-chat",  # 或 DeepSeek 提供的其他聊天模型名稱
        "messages": [
            {"role": "user", "content": filled_prompt}
        ],
        "temperature": 0.7,  # 調整創意度，0.0 為最保守，1.0 為最有創意
        "max_tokens": 1500  # 設定最大返回 token 數量
    }

    try:
        response = requests.post(API_ENDPOINT, headers=headers, json=payload)
        response.raise_for_status()  # 檢查 HTTP 錯誤
        
        response_data = response.json()
        
        # 提取模型生成的文本內容
        if response_data and response_data.get('choices'):
            message_content = response_data['choices'][0]['message']['content']
            
            # DeepSeek 有時會在 JSON 前後加入額外的文字，需要處理
            try:
                # 尋找 JSON 的起始和結束標記
                json_start = message_content.find('{')
                json_end = message_content.rfind('}') + 1
                
                if json_start != -1 and json_end != -1 and json_end > json_start:
                    json_string = message_content[json_start:json_end]
                    return json.loads(json_string)
                else:
                    print("Error: Could not find valid JSON in response.")
                    print(f"Raw response content: {message_content}")
                    return None
            except json.JSONDecodeError as e:
                print(f"JSON 解碼錯誤: {e}")
                print(f"原始響應內容: {message_content}")
                return None
        else:
            print(f"未從 DeepSeek 收到有效的響應數據: {response_data}")
            return None

    except requests.exceptions.RequestException as e:
        print(f"API 請求失敗: {e}")
        return None

# --- 測試調用 ---
if __name__ == "__main__":
    # 確保 DEEPSEEK_API_KEY 環境變數已設定，或者在此處直接替換 "YOUR_DEEPSEEK_API_KEY"
    if DEEPSEEK_API_KEY == "YOUR_DEEPSEEK_API_KEY":
        print("警告：請將 DEEPSEEK_API_KEY 替換為您的實際金鑰或設定為環境變數。")
    
    user_input = {
        "user_interest": "美食、文化探索",
        "user_budget": "中等",
        "user_time": "上午9點至下午7點",
        "user_pax": "2位成人",
        "user_preferences": "希望體驗地道小吃和傳統市集，避免過於商業化的連鎖店。",
        "user_departure": "上環"
    }

    itinerary = get_personalized_itinerary(**user_input)

    if itinerary:
        print("\n--- DeepSeek 生成的香港一日遊行程 ---")
        print(json.dumps(itinerary, ensure_ascii=False, indent=4))
    else:
        print("\n未能成功生成行程。")

```
