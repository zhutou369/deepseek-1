## 理解思維鏈 (Chain-of-Thought, CoT) 提示詞的原理

思維鏈提示詞是一種引導大型語言模型（LLM）逐步思考、分解問題的技術。它要求模型在提供最終答案前，展示其推理過程。這對於處理複雜任務尤為關鍵，因為：

1.  **提升準確性：** 迫使模型「思考」每一步，減少直接跳到結論的錯誤。
2.  **增強可解釋性：** 用戶可以追溯模型的推理路徑，理解其邏輯。
3.  **處理複雜性：** 能將一個龐大、多步驟的問題分解為一系列小型、易於管理的子問題。

在金融圖表分析中，這意味著 DeepSeek 不僅會給出「買入」或「賣出」的建議，更會闡明其判斷基於哪些圖表元素、技術指標變化以及市場背景，從而提供一個透明且可靠的分析框架。

## DeepSeek 處理金融圖表前的準備工作

在建構提示詞之前，確保您已做好以下準備：

1.  **存取 DeepSeek 平台：**
    透過瀏覽器訪問 [chat.deepseek.com](https://chat.deepseek.com) 即可開始使用 DeepSeek 的對話介面。若需將分析流程自動化，則會涉及到 DeepSeek API 的調用。

2.  **數據整理與格式化：**
    DeepSeek 目前主要處理文字信息，因此需要將視覺化的金融圖表轉換為文字描述。這包括：
    *   **圖表類型：** K線圖、折線圖、柱狀圖、餅圖等。
    *   **時間範圍：** 例如「2023年1月1日至2023年6月30日」。
    *   **主要趨勢：** 上升、下降、盤整。
    *   **關鍵數據點：** 開盤價、收盤價、最高價、最低價、成交量、特定日期的高點/低點。
    *   **技術指標數據：** MACD（快線、慢線、柱狀圖）、RSI、布林帶（上軌、中軌、下軌）等具體數值或相對位置。
    *   **相關事件：** 可能影響市場的宏觀經濟數據、公司財報、政策變動等背景信息。

    越詳盡、結構化的文字描述，DeepSeek 的分析會越精準。

3.  **明確分析目標：**
    您希望 DeepSeek 從圖表分析中獲得什麼？是短期趨勢預測、長期投資策略、風險評估，還是特定事件的影響分析？清晰的目標有助於 DeepSeek 聚焦輸出。

## 建構高效能 DeepSeek 思維鏈提示詞的策略

以下是建構一個強大思維鏈提示詞的五個核心步驟，每個步驟都將透過具體範例說明。

### 步驟一：明確問題與目標

在提示詞開頭，清晰地定義您的角色需求和具體分析任務。

**提示詞範例片段：**
```
「請你作為一名資深金融分析師，任務是分析以下恒生指數日線圖的數據，並基於思維鏈邏輯提供詳細解讀和潛在投資建議。我的目標是理解過去六個月的市場走勢，並評估短期（未來1-2週）的投資機會與風險。」
```

### 步驟二：拆解圖表元素與輸入數據

明確告訴 DeepSeek，它需要處理哪些圖表資訊。這部分是將您的圖表數據轉換為 DeepSeek 能理解的文字輸入。

**提示詞範例片段（承接上文）：**
```
「圖表數據描述如下：
- **時間範圍：** 2023年1月1日至2023年6月30日（共六個月）。
- **主要價格趨勢：** 1月至2月中旬震盪上行，從約 20,000 點升至 22,000 點；2月下旬至4月下旬急劇下跌，跌破 19,000 點關口；5月至6月下旬在 18,500 至 19,500 點之間窄幅盤整。
- **關鍵價格點：** 1月15日觸及高點 22,000 點；4月10日跌至低點 18,000 點；目前（6月30日收盤）在 19,000 點附近。
- **成交量分析：** 1月上行階段伴隨溫和放量；2月下旬至4月下旬下跌時伴隨巨量，特別是跌破關鍵支撐位時；5月至6月盤整區間成交量顯著萎縮。
- **MACD指標：** 2月初出現死叉（快線下穿慢線），MACD柱狀圖轉綠並持續擴大；4月中旬MACD出現金叉，但柱狀圖未能有效轉紅且反彈乏力；目前MACD線仍在零軸下方徘徊。
- **RSI指標（14天）：** 3月中旬RSI跌破30進入超賣區；5月底RSI反彈至50附近，但未能有效突破，隨後再度回落至45左右。
- **相關宏觀事件：** 期間香港及內地經濟數據波動，美國聯儲局加息預期不斷增強，全球通脹壓力持續。
」
```

### 步驟三：引導邏輯推理（思維鏈核心）

這是思維鏈提示詞的精髓。您需要指示 DeepSeek 按照一系列邏輯步驟進行分析，而非直接給出結論。

**提示詞範例片段（承接上文）：**
```
「請你依照以下嚴謹的步驟進行思維鏈分析：
1.  **圖表整體概覽：** 首先，請宏觀描述恒生指數在這六個月的整體走勢特徵及各階段變化。
2.  **主要趨勢與轉折點分析：** 詳細識別上升、下降及盤整階段，解釋每個階段的力度、持續時間，並標示關鍵轉折點。
3.  **價格與成交量關係解析：** 結合不同階段的價格走勢與成交量變化，分析市場情緒和資金動向（例如，下跌放量是否為恐慌性拋售，盤整縮量是否為觀望）。
4.  **技術指標交叉驗證：** 深入解讀 MACD 和 RSI 指標的具體變化（金叉、死叉、超買、超賣、背離等），它們如何與價格走勢相互印證或提供前瞻性信號。
5.  **宏觀事件與市場情緒關聯：** 結合上述提到的宏觀經濟事件，分析它們可能對恒生指數走勢產生的影響，以及市場參與者的情緒變化。
6.  **綜合判斷與風險評估：** 綜合所有圖表、指標及宏觀因素分析，對恒生指數當前市場狀況給出清晰判斷（牛市、熊市、震盪市），並評估潛在的上升與下跌風險。
7.  **投資策略建議：** 基於上述綜合判斷和風險評估，針對短期（未來1-2週）提供具體的投資策略建議（如買入/賣出/持有、建議止損止盈位、倉位管理等）。

請以專業、清晰、結構化的格式輸出分析結果。」
```

### 步驟四：融入金融知識與背景

雖然 DeepSeek 具備廣泛的知識，但提供特定領域（如香港本地市場、特定行業）的額外背景信息，能讓分析更貼近實際。在步驟二的「相關宏觀事件」中已體現。

### 步驟五：驗證與迭代

DeepSeek 的首次輸出可能不完美。仔細審閱其推理過程和結論，若有不清晰或錯誤之處，可以透過追問或修改原提示詞來進行迭代。

**例如，您可以追問：**
*   「請進一步解釋 MACD 死叉後為何反彈乏力，是否與某特定事件有關？」
*   「在當前盤整區間，RSI 保持在 45 左右，這對未來走勢有何啟示？」

**DeepSeek 輸出示例（部分）：**

```
**恒生指數六個月走勢思維鏈分析報告**

**1. 圖表整體概覽：**
恒生指數在2023年1月至6月的六個月內，呈現出「先升後跌再盤整」的明顯三階段特徵。整體而言，市場經歷了較大的波動，未能形成明確的單邊趨勢，當前處於底部盤整階段，顯示市場情緒謹慎。

**2. 主要趨勢與轉折點分析：**
*   **震盪上行階段 (1月至2月中旬):** 指數從約 20,000 點升至 22,000 點，漲幅約 10%。此階段表現為震盪但重心不斷上移，顯示初步的樂觀情緒和買盤介入。關鍵轉折點為 2 月中旬的 22,000 點，之後未能突破並開始回落。
*   **急劇下跌階段 (2月下旬至4月下旬):** 指數從 22,000 點迅速跌破 19,000 點關口，最低觸及 18,000 點，跌幅顯著。此階段的下跌速度快、幅度大，顯示市場恐慌情緒蔓延，賣壓沉重。轉折點為 4 月中旬的 18,000 點，此後跌勢趨緩。
*   **窄幅盤整階段 (5月至6月下旬):** 指數在 18,500 點至 19,500 點之間窄幅波動，未能有效突破上方壓力或跌破下方支撐。此階段市場缺乏明確方向，多空雙方力量均衡，觀望氣氛濃厚。目前位於 19,000 點附近。

**3. 價格與成交量關係解析：**
*   **1月上行階段：** 溫和放量伴隨價格上漲，表明資金逐步入場，市場信心有所恢復，但並未出現過度狂熱。
*   **2月至4月下跌階段：** 伴隨巨量下跌，尤其是在跌破關鍵支撐位時，成交量顯著放大。這強烈暗示恐慌性拋售與止損盤湧出，市場流動性壓力較大，是典型的大量換手伴隨價格下挫的熊市特徵。
*   **5月至6月盤整階段：** 成交量顯著萎縮，表明市場交投清淡，多空雙方均不願大幅投入，資金觀望情緒濃厚，預示短期內可能難以形成趨勢性行情。

**4. 技術指標交叉驗證：**
*   **MACD指標：**
    *   2月初的死叉預警了隨後的下跌趨勢，MACD柱狀圖持續擴大為負值，進一步確認了空頭力量的強勢。
    *   4月中旬的金叉原本是看漲信號，但其後 MACD 柱狀圖未能有效轉紅且反彈乏力，這是一個「假金叉」或「弱勢金叉」，表明市場動能不足，未能真正扭轉頹勢。
    *   目前 MACD 線仍在零軸下方徘徊，提示整體市場仍處於空頭格局。
*   **RSI指標：**
    *   3月中旬 RSI 跌破 30 進入超賣區，預示短期內存在反彈需求，而 4 月中旬的指數反彈也印證了這一點。
    *   5月底 RSI 反彈至 50 附近後再度回落至 45 左右，未能有效突破 50 中軸線，這表明多頭力量未能佔據優勢，市場信心不足，未能從超賣區有效走出。

**5. 宏觀事件與市場情緒關聯：**
*   **經濟數據波動：** 香港及內地經濟數據的不確定性可能影響市場對企業盈利的預期，導致投資者情緒波動。
*   **美國聯儲局加息：** 全球加息預期，尤其是美國聯儲局的貨幣政策，對香港市場資金流向構成壓力。港元聯繫匯率制度下，美息上升會導致港息跟隨，進而影響本地企業融資成本及資產估值，增加了市場的下行壓力。
*   **全球通脹壓力：** 高通脹可能抑制消費，並對企業營運成本造成壓力，進一步削弱投資者信心。
綜合來看，宏觀層面的負面因素是導致 2 月至 4 月急劇下跌的主要驅動因素，而隨後的盤整則反映了市場對未來走向的不確定性和謹慎態度。

**6. 綜合判斷與風險評估：**
綜合上述分析，恒生指數目前處於底部震盪市，短期內缺乏明確的方向性。技術指標（MACD 零軸下方，RSI 未能有效突破 50）均顯示市場仍偏弱，上方壓力較大。儘管指數曾在 18,000 點附近獲得支撐，但成交量萎縮和反彈乏力表明多頭動能不足。宏觀經濟環境的不確定性，尤其是全球加息壓力，將繼續對市場構成壓力。
*   **上升風險：** 潛在利好消息（如內地經濟超預期復甦、地緣政治緩和）可能引發短期反彈。
*   **下跌風險：** 若全球經濟數據進一步惡化，或地緣政治風險加劇，指數可能再次測試甚至跌破 18,000 點的支撐位。

**7. 投資策略建議（短期1-2週）：**
鑑於當前市場處於底部盤整且缺乏明顯趨勢，投資者應採取以下策略：
```
